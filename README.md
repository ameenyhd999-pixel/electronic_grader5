تطبيق Flutter عربي يعمل محليًا لإدارة الاختبارات وتصحيح أوراق الإجابة.

## بدء التشغيل

يتطلب Flutter SDK مع Dart المرفق به. من جذر المشروع شغّل:

```sh
flutter pub get
flutter analyze
flutter test
flutter run
```

لإنشاء ملفات منصة Android القياسية عند العمل في بيئة Flutter محلية:

```sh
flutter create --platforms=android .
```
